# 像素画造型、色簇组织、光影色阶与抖动规范

## 1. 分辨率选型与细节密度

| 原生画布 | 典型用途 | 核心造型策略 |
| :--- | :--- | :--- |
| `16x16` ~ `24x24` | 背包道具图标、迷你 RPG 棋子、状态 Buff | **符号化夸张**：头部占身高 1/2，眼睛仅用 `1x2` 或 `2x2` 纯色块，省略手指与细碎衣褶 |
| `32x32` ~ `48x48` | 横版动作主角、怪物精英、宝箱交互物 | **色簇（Cluster）塑形**：用 `>=2px` 的成片色块表达木纹、护甲高光与牙齿层次；用 `Rig` 拆件 |
| `64x64` ~ `128x128` | Boss 立绘、半身对话头像、精细场景物件 | **几何底稿 + 局部印章**：用 `PixelCanvas` 铺大体积剪影与 Bayer 抖动过渡，再局部精修五官 |

## 2. 四大像素画常见病与根治手法

1. **孤立碎像素（Orphan Noise）**：
   - 错误：为表现粗糙材质随机撒单像素点，缩放到 1x/2x 时像脏噪点。
   - 正解：除眼球高光点、星芒尖端外，同色像素应组成 `2x1`、`2x2`、`L` 型或条带状**色簇（Cluster）**。
2. **阶梯锯齿（Jaggies）与直角双像素（L-Corners）**：
   - 错误：平滑曲线出现 `3 -> 1 -> 3` 的突变台阶，或斜线拐角多出直角堆积像素。
   - 正解：曲线阶梯长度必须单调递减/递增（如 `4 -> 2 -> 1 -> 1 -> 2 -> 4`）；手绘直线或多边形边框优先调用 `PixelCanvas.line(..., pixel_perfect=True)`。
3. **枕头阴影（Pillow Shading）与色带粘连（Banding）**：
   - 错误：不分光源方向，一圈圈像同心圆一样往中心提亮（枕头阴影）；或相邻两层色阶的像素阶梯完全平行对齐（Banding）。
   - 正解：严格固定**左上角主光源**（`light_dir=(-1, -1)`）。左上受光面厚亮，右下背光面压暗，高光簇与暗部簇打破平行阶梯。
4. **死黑描边过重**：
   - 正解：启用 `selective_outline(img, light_dir=(-1, -1), snap_palette=...)` 或 `Rig(..., outline_mode="selout")`，让受光侧外轮廓自动染上主色暗调，背光侧保持深色锚定，立体感立竿见影。

## 3. 色相偏移明暗色阶（Hue-Shifted Ramps）

切忌单纯加白/加黑调配明暗！使用 `generate_shading_ramp(base_hex, steps=4)` 或在内置色板中遵循：
- **高光（Highlight）**：提亮的同时色相向**暖黄/青白**微偏，适当降低高光处饱和度。
- **暗部（Shadow）**：压暗的同时色相向**冷蓝/紫靛**微偏，适当提高暗部饱和度，避免画面发灰发焦。
- **推荐 `PALETTE_ENDESGA32` 常用材质语义组合**：
  - 钢铁/银刃：`W`（刃口高光）→ `1`（亮面）→ `2`（中调）→ `3`/`4`（背光暗面）→ `K`（深轮廓）
  - 黄金/铜扣：`y`（极亮）→ `Y`（金主色）→ `O`（暗金）→ `o`/`l`（深铜阴影）
  - 原木/箱体：`s`（受光木棱）→ `L`（木板主色）→ `l`（木缝暗部）→ `e`（深腔阴影）
  - 火焰/魔法：`W` → `y` → `Y` → `O` → `R` → `r`

## 4. 有序抖动（Ordered Bayer Dithering）

需要大面积明暗过渡（如天空背景、披风暗面、魔法光晕）时，调用 `PixelCanvas.dither_rect(..., only_on_char="B", ratio=0.25|0.5)`：
- `matrix_size=2, ratio=0.5`：经典 `50%` 棋盘格交错过渡。
- `matrix_size=4, ratio=0.25`：稀疏颗粒纹理过渡，适合石砖或布料质感。
- 小尺寸角色（`<=32x32`）主体内部尽量少用抖动，保持干脆利落的赛璐璐色块。
